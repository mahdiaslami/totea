# 🧠 Totea (توتیا)

**Your Smart, Simple Persian Life & Task Planner**

توتیا، اپلیکیشن برنامه‌ریزی روزانه و مدیریت کارهای شخصی به تقویم شمسی بر پایهٔ Capacitor و Vue 3.

---

### 🚀 ویژگی‌های فنی و تجربه کاربری (UX)
- **مدیریت روان کیبورد (Fluid Keyboard Handling):**
  - جلوگیری کامل از پرش محتوا (Zero Viewport Jump) با تکنیک `Keyboard.resize = 'none'`.
  - انیمیشن سخت‌افزاری بر پایهٔ `transform` بدون لگ یا افت فریم (هیچ انیمیشنی روی `height` بسته نمی‌شود).
  - استفاده از منحنی شتاب `ease` متناسب با شتاب کیبورد بومی iOS و اندروید.
  - مستندات کامل تکنیک در [docs/KEYBOARD_HANDLING.md](./docs/KEYBOARD_HANDLING.md).
